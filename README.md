# 吐出量填報計算機（PWA 離線版）

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | App 本體（畫面與計算） |
| `manifest.webmanifest` | App 名稱、圖示、全螢幕設定 |
| `sw.js` | 離線快取（第一次開啟後即可離線使用） |
| `icons/` | App 圖示（Android、iPhone、瀏覽器分頁） |

> 這些檔案必須放在 **https** 網址上才能安裝成 App、離線使用。直接在手機上點開 `index.html` 檔案無法離線安裝。

---

## 一、放上 GitHub Pages（免費，約 10 分鐘）

1. **註冊帳號**：到 https://github.com 註冊並登入。
2. **建立儲存庫**：右上角「＋」→「New repository」。
   - Repository name 填 `gp-calc`（英文、可自訂，會出現在網址中）。
   - 選 **Public**（免費帳號的 GitHub Pages 需要公開儲存庫）。
   - 按「Create repository」。
3. **上傳檔案**：在新儲存庫頁面點「uploading an existing file」。
   - 把解壓縮後的 **所有檔案與 `icons` 資料夾** 一起拖進去（`index.html` 要在最上層，不要多包一層資料夾）。
   - 下方按「Commit changes」。
4. **開啟 Pages**：儲存庫上方「Settings」→ 左側「Pages」。
   - Source 選「Deploy from a branch」。
   - Branch 選 `main`、資料夾 `/ (root)`，按「Save」。
5. **取得網址**：等 1～2 分鐘後重新整理該頁，上方會顯示：
   `https://你的帳號.github.io/gp-calc/`
   用電腦開一次確認畫面正常，就可以把這個網址傳給同事。

> 注意：公開儲存庫代表任何人都看得到這份程式碼與機號吐出量數值。若公司不允許，可改用公司內部的 https 網站伺服器存放，步驟只是把同樣的檔案放上去。

## 二、同事安裝到手機

**第一次安裝時手機需要連網**，之後在沒有網路的現場也能開啟使用。

### Android（Chrome）
1. 用 **Chrome** 開啟網址。
2. 畫面下方若出現「安裝應用程式」直接點；沒有的話點右上角「⋮」→「安裝應用程式」或「加到主畫面」。
3. 主畫面會出現「吐出量計算」圖示。

### iPhone（Safari）
1. 必須用 **Safari** 開啟網址（LINE 內建瀏覽器或 Chrome 不行，請點右下角「用 Safari 開啟」）。
2. 點下方「分享」按鈕（方框加向上箭頭）。
3. 往下滑選「加入主畫面」→ 右上角「加入」。
4. 主畫面會出現「吐出量計算」圖示。

## 三、日後更新（例如修改機號吐出量）

1. 修改 `index.html` 最下方程式中的 `RATES` 對照資料，例如：
   ```js
   '01': [1.09, 0.48],   // [主GP吐出量, 副GP吐出量]
   ```
   新增機號就照格式多加一行。
2. 打開 `sw.js`，把第 2 行 `var VERSION = 'v1';` 改成 `'v2'`（每次更新都加 1）。
3. 到 GitHub 儲存庫按「Add file」→「Upload files」，上傳改過的檔案覆蓋，按「Commit changes」。
4. 同事的手機在 **連網時打開 App**，會在背景下載新版；**關掉再開一次** 就會是新版本。

---

## 四、使用須知

- 排廢中的資料會即時存在手機上，中途關掉 App、切到其他程式或重新整理都不會遺失，回來後時間會繼續累計。
- 「歷史紀錄」只存在該支手機上，最多保留最近 200 筆；清除瀏覽器資料或刪除 App 會一併刪除。
- 「複製結果」可把結果貼到 LINE 或填報系統。
- iPhone 上，若 App 太久沒開（數週），系統可能清除它的資料，重要紀錄請及時填報。
